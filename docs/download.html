What's new in 1.3.1

  • Square tab grid with page previews. Every tab shows a picture of the page, two to a row. Closing a tab no longer throws you out of the tab screen.
  • Pick your download manager. When something downloads, choose the built-in downloader or an app you already have (ADM and similar), and keep that choice.
  • Steadier player. The progress bar no longer jumps forward and back on its own while a video plays in landscape.
  • Thin border on every tab card, a thicker one on the active tab, and a divider under the preview.

Install

  1. Tap the download button and wait for the file to finish.
  2. Open the file from your browser or file manager. If Android asks, allow installs from this source.
  3. Tap Install, then open the app. Set it as your default browser from the menu if you want.

Updates install over the old version and keep bookmarks, history and settings. Every release is signed with the same key, so Android accepts the upgrade without uninstalling.

Check the file

On a phone with a terminal app, or on a computer:

sha256sum SkybleBrowser-1.3.1.apk

The output must match the SHA-256 above. A different hash means the file is not the official build.

Other download sites copy this app and can keep an older version for months. Check the version in the file name before installing. The newest build is always on this page and on the GitHub release page.

Permissions

The app asks for five permissions and nothing else:

  • Internet and network state — load pages and check whether a connection exists.
  • Notifications — show download progress and a finish notice, including a button to open the file.
  • Write storage — save downloads to the shared Download folder on older Android versions.
  • Install packages — used only when you install an update from inside the app.

Questions

Which version is the newest?

1.3.1, released 27 November 2026. The GitHub release page and this page always show the same build.

Why is the app so small?

There is no bundled browser engine. Pages are drawn by the Android System WebView that is already on the phone, so the app stays small and gets engine security updates. About 2 MB of the 2.9 MB download is the video player. with the system.

Is there a Bengali version?

One app, two interface languages. Settings opens with a language switch, and the Bengali translation covers the whole interface.

Where do I report a problem?

Open an issue on GitHub.
